Prometheus Metrics Design

Metrics exposed at /metrics for Grafana dashboard panels

指标名 类型 标签 对应需求
opencode_interactions_total Counter session, tool 交互次数
opencode_tokens_total Counter session, direction(input/output) Token 消耗
opencode_context_size_bytes Gauge session 上下文变化趋势
opencode_compactions_total Counter session Compaction 次数
opencode_context_expansion_total Counter session, tool 快速膨胀事件
阈值: 单次增长 >50%
opencode_tool_duration_seconds Histogram session, tool 工具调用耗时分布
opencode_compaction_tokens_removed Histogram session 每次压缩移除的 token 分布

Grafana Panel 映射

Dashboard Row 1: Overview
Stat: 交互总次数
opencode_interactions_total
Stat: Token 总消耗
opencode_tokens_total
Stat: Compaction 次数
opencode_compactions_total
Time Series: 上下文大小变化趋势 (Gauge)
opencode_context_size_bytes
Dashboard Row 2: Analysis
Bar Gauge: 各工具调用次数分布
opencode_interactions_total by tool
Heatmap: 工具调用耗时
opencode_tool_duration_seconds
Time Series: 上下文膨胀事件
opencode_context_expansion_total by tool
